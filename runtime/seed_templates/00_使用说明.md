# 模型蒸馏种子模板

这些是明确标注的格式示例，用于学习输入结构和小样本试用，不是生产业务数据或模型效果基准。系统不会自动将它们登记到用户数据集，也不会创建任务。正式训练请换成经过审核的业务种子，并另备独立测试集。

## 如何使用

1. 根据任务配方选择下表中的 JSONL 文件，下载后可在“模型蒸馏 → 我的数据集 → 上传”中上传。
2. 查看首条样本和字段，确认与配方一致，再创建蒸馏任务。示例仅有两条，不能据此判断模型效果；教师生成、质量筛选可能使最终条数变化，甚至全部被过滤。
3. 替换或增加自己的记录，保留需要的字段名和类型。当前建议使用 UTF-8 无 BOM 的 JSONL，每行一个 JSON 对象，不写表头、不加行尾逗号；也支持由对象组成的 JSON 数组。至少包含一条记录。CSV、Excel、Word、PDF 不可直接作为当前任务输入。

| 文件 | 适用配方 | 本模板必填字段 |
|---|---|---|
| 01_指令与偏好数据种子.jsonl | 基础指令、高质量指令、指令增强、类别均衡、DPO 偏好数据生成 | instruction：非空字符串 |
| 02_思维链生成种子.jsonl | 思维链生成、思维链评分与难度混合 | problem：非空字符串 |
| 03_思维链压缩与扩展种子.jsonl | 思维链压缩、思维链扩展 | problem、answer：非空字符串 |
| 04_已有回答质量评估样例.jsonl | 指令数据质量评估、思维链质量评估 | instruction、output：非空字符串 |
| 05_智能体角色与背景种子.jsonl | Agent 工具轨迹蒸馏 | persona：非空角色或背景描述 |
| 06_搜索智能体问答种子.jsonl | 搜索 Agent 蒸馏 | question、answer：非空问题及参考答案 |
| 07_多模态图文蒸馏种子.jsonl | 多模态指令蒸馏、多模态思维链蒸馏 | instruction：非空字符串；images：非空字符串数组 |

本表列出模板采用的规范字段，部分配方也接受别名或 messages 对话，详情以 `/workflows` 和任务预览校验为准。输入存在其他字段名时，配置“字段映射”；例如原字段为 question，指令任务可使用 `{"instruction":"question"}`。不能仅凭文件上传成功判断配方字段已合格。

基础指令、高质量指令、指令增强、类别均衡配方，也支持把已有的单轮 SFT `messages` 数据重新用于蒸馏：若没有 instruction，自动提取唯一 user 消息的文本作为种子，原 assistant 回答不会当作新教师回答。允许可选 system、一个 user、可选 assistant；任务的 system_prompt 继续生效。原文件不修改，只在任务输入快照添加 instruction。多轮、工具或图文消息不自动展平，请先整理对应字段或选择合适配方。显式 instruction 和字段映射优先。

## 多模态图片

`07_多模态图文蒸馏种子.jsonl` 内嵌真实可解码的 PNG 示意图：从左到右是两个蓝色正方形、一个橙色圆形。无需外网、额外图片上传或修改服务器路径即可试用；包内 `08_多模态示例图片.png` 为同一图片，便于查看。

自己的图文数据可使用 `images: ["data:image/png;base64,..."]`，或把图片放到当前用户 JFS 目录，使用文件路径。相对路径以所上传种子文件的实际存放目录为基准；单独上传 JSONL 不会同时上传本机旁边的图片。禁止引用其他用户目录或外网图片。不要把 Windows 本机路径当作服务器可访问路径。教师必须支持视觉；开启学生训练还须选视觉基模。

## 内容和能力边界

- 指令、DPO 和思维链生成种子通常不要求已有答案；思维链改写、搜索 Agent、独立质量评估要求已有回答或参考答案。
- 企业制度、产品说明等业务上下文建议直接写入问题或角色背景；额外 input 字段不会由所有配方自动拼入指令。
- Agent 原生模拟工具用于合成训练轨迹，不能将其理解为已经查询真实工单或业务系统。搜索 Agent 离线使用模拟搜索模式；样例提供已知参考答案，但不证明生成轨迹经过真实联网核查。
- 内网教师服务、模型权重和计算资源需要另外准备，模板不提供这些运行环境。
- 下载模板不写数据库、不占用户数据集列表；用户主动上传后才形成该用户自己的数据资产。
